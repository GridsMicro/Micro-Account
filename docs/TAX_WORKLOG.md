### งานวันนี้ (มาจาก TODO รอบที่ 1)

1. **แก้ `tax:update` output ถูกตัด → สาเหตุชัดเจน:**
   - RSS `https://www.rd.go.th/rss/tax-updates.xml` ตรวจจริง 2026-09-21 → **HTTP 500 (~10 วิ)** — RD ปรับโครงเว็บ ฟีดนี้เสีย
   - ตรวจ feed ทางเลือกของ RD: `publish/RSS/rss_taxform.xml` ก็ 500; `interapp4.rd.go.th/TPW/pages/rss_procure.xml` ใช้ได้ (200) แต่เป็นข่าวจัดซื้อไม่ใช่ภาษี
   - **แก้:** `services/taxUpdater.ts` เพิ่ม timeout 15 วิ (AbortController) + ทั้งที่ RSS ล่มคืนข้อความเตือน ไม่ throw ค้าง
   - ผล: `npm run tax:update` → exit 0 จบสมบูรณ์ ไม่ตัด output อีก

2. **แก้ PP.30 Input VAT ให้มาจากข้อมูลจริง (เจอบั๊กที่ทำเงินยื่นเพี้ยน):**
   - เดิม: `SUM(amount * 0.07)` จาก `payment_vouchers` → สมมุติทุกใบมี VAT 7% + ก.ย.2026 ไม่มี voucher เลย = 0
   - ตรวจจริง: ก.ย.2026 มี **VAT ซื้อจริง 1,909.17 บาท** ใน `expenses` (Google Workspace 65.42 + 1,843.75) แต่ `tax_deductible = NULL` → ไม่ถูกนับ
   - **แก้:** `getPP30Draft` หา Input VAT จาก `expenses.vat_amount` (WHERE tax_deductible=true AND vat_amount>0) + เพิ่ม `missingDeductibleTax` แจ้งเตือนเมื่อมี VAT ซื้อแต่ยังไม่ flag หักได้
   - ผล: ถ้า flag รายการนั้นเป็น deductible → Net VAT จะลดจาก 2,445.45 เหลือ 536.28

3. **แก้ ภ.ง.ด.53 WHT ให้คำนวณเอง (เดิมคืน 0 ตลอด):**
   - เดิม: join ผ่าน `payment_vouchers.expense_id` (ก.ย.=0 ใบ) + รอ `withholding_tax_amount` ที่ไม่มีใครกรอก
   - **แก้:** `getPNDReportDraft` คำนวณจาก `expenses` ตรง: `COALESCE(withholding_tax_amount, ROUND(wht_rate/100 * net_amount,2))`
   - ผล: ภ.ง.ด.53 ก.ย.2026 = **818.22 บาท (2 รายการ)**

4. **เพิ่มลิงก์ e-Filing ภ.ง.ด.53 / ภ.ง.ด.51 (จากพี่กีโร่):**
   - `lib/taxAutomator.ts` → `TAX_FILING_URLS.pnd53 = https://efiling.rd.go.th/rd-efiling-web/tax/wht/pnd53`, `pnd51 = https://efiling.rd.go.th/rd-efiling-web/tax/cit/pnd51/step-1`
   - ตรวจทั้ง 2 ลิงก์แล้ว HTTP 200 จริง (ยื่นข้ามเดือนได้ด้วยกัน แต่ควรมีไว้ให้รู้ว่าถ้ามีรายการต้องยื่น)
   - UI `app/tax-reports/page.tsx` ใช้ `TAX_FILING_URLS[form.id]` → ปุ่มกลายเป็นลิงก์อัตโนมัติ ไม่ต้องแก้หน้า
   - ยังว่าง: `pnd3` (ไม่มีลิงก์ตรงจาก RD)
