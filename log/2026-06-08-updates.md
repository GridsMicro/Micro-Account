# บันทึกการอัปเดตและปรับปรุงระบบ - 2026-06-08

## 1. แก้ไขการแสดงผลภาษีหัก ณ ที่จ่าย (WHT) ในหน้าพิมพ์ใบเสร็จ
- **ปัญหา:** หน้าพิมพ์ใบเสร็จรับเงิน ([page.tsx](file:///c:/Users/User/Documents/GitHub/GridsMicro/Micro-Account/app/payments/print/[id]/page.tsx)) ไม่แสดงรายการ หัก ณ ที่จ่าย (WHT) สำหรับรายการชำระเงินบางรายการ (เช่น ID 9) แม้ว่าจะมีการหักภาษีจริง
- **สาเหตุ:** โค้ดเดิมดึงค่า WHT จาก `invoice_wht_amount` เพียงอย่างเดียว ซึ่งรายการชำระเงินที่สร้างแบบ Manual หรือข้อมูลบางส่วนอาจเก็บค่า WHT ไว้ที่ระดับ Payment (`wht_amount`) หรือใช้ฟิลด์ Legacy (`withholding_amount`)
- **การแก้ไข:**
    - ปรับปรุง Interface `Payment` ให้รองรับฟิลด์ `wht_amount`
    - เพิ่มตรรกะ Fallback ในการดึงค่า WHT โดยตรวจสอบตามลำดับ: `wht_amount` -> `invoice_wht_amount` -> `withholding_amount`
    - ปรับปรุงการคำนวณยอดสุทธิ (Total) ให้รองรับกรณีที่ไม่มีข้อมูล `invoice_net_after_wht` โดยคำนวณจาก `Subtotal + VAT - WHT` แทน
- **ผลลัพธ์:** หน้าพิมพ์ใบเสร็จแสดงรายการ WHT และยอดรวมสุทธิได้ถูกต้องครอบคลุมทุกกรณี
