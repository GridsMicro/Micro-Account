## Core Marketing Skills

### 1. **Product-Marketing Foundation** 
   - **Purpose:** Establish clear product positioning, audience definition, and messaging framework
   - **Use When:** Planning campaigns, defining customer segments, positioning new products
   - **Key Outputs:**
     - Customer avatar definition (demographics, pain points, job-to-be-done)
     - Unique value proposition (UVP)
     - Core messaging pillars
     - Target market sizing

### 2. **Conversion Rate Optimization (CRO)**
   - **Purpose:** Improve website/funnel conversion rates through testing and data analysis
   - **Use When:** Analyzing landing pages, A/B testing variations, optimizing checkout flow, reducing bounce rates
   - **Framework:**
     - Heatmap analysis → identify friction points
     - User flow mapping → conversion bottlenecks
     - Test hypothesis generation → lift prediction
     - Analytics dashboard setup → continuous optimization
   - **Tools Referenced:** Google Analytics, Hotjar, Unbounce, Converly (conversion tracking)

### 3. **Content & Copywriting**
   - **Purpose:** Craft compelling, audience-focused copy for different channels
   - **Use When:** Writing landing page copy, email campaigns, ad creative, product descriptions
   - **Frameworks:**
     - AIDA (Attention, Interest, Desire, Action)
     - Jobs-to-be-Done messaging
     - Headline formulas (benefit-driven, curiosity-gap, pattern-break)
     - Social proof integration

### 4. **SEO & Organic Growth**
   - **Purpose:** Improve search visibility and organic traffic through technical/content SEO
   - **Use When:** Planning keyword strategy, analyzing SERP positions, optimizing on-page content, building backlinks
   - **Key Tasks:**
     - Keyword research (search intent, volume, competition)
     - On-page optimization (meta tags, headers, schema markup)
     - Technical SEO audit (site speed, mobile, crawlability)
     - Content gap analysis
   - **Tools Referenced:** Semrush, Ahrefs, SEMrush, AIsa, DataForSEO, Similarweb

### 5. **Analytics & Data-Driven Decision Making**
   - **Purpose:** Interpret marketing metrics and guide strategy with data
   - **Use When:** Reporting campaign performance, analyzing funnel metrics, forecasting ROI, setting benchmarks
   - **Key Metrics:**
     - Acquisition cost (CAC), customer lifetime value (LTV)
     - Conversion rate (CR), click-through rate (CTR)
     - Attribution and multi-touch modeling
     - Cohort analysis

### 6. **Growth Engineering**
   - **Purpose:** Identify and scale high-impact growth levers systematically
   - **Use When:** Planning product-led growth, referral programs, retention loops, viral mechanics
   - **Frameworks:**
     - Growth Loops (acquisition → activation → retention → monetization)
     - Pirate Metrics (AARRR: Awareness, Acquisition, Activation, Revenue, Retention)
     - Product-market fit signals

## Marketing Frameworks & Checklists

### Campaign Planning Checklist
- [ ] Define campaign objective (awareness, lead gen, sales, retention)
- [ ] Identify target audience and personas
- [ ] Select channels (paid, organic, direct, partnership)
- [ ] Create messaging + creative assets
- [ ] Set budget and expected ROI
- [ ] Plan measurement framework (KPIs, tracking pixels)
- [ ] Timeline and dependencies
- [ ] A/B test plan (if applicable)

### Launch Readiness Checklist
- [ ] Product messaging finalized
- [ ] Landing page live + tested
- [ ] Email/SMS templates ready
- [ ] Social/paid ads creative approved
- [ ] Press release (if applicable)
- [ ] Analytics dashboard live
- [ ] Team briefing complete
- [ ] Launch day checklist (timing, channels, monitoring)
